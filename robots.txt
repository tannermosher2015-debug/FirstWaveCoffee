# This is a CONCEPT / design-preview site by Frontline Web Designs, not the
# official First Wave Coffee website. It must stay out of search results so it
# never competes with or impersonates the real business. That goal has NOT
# changed and this site has NOT been adopted.
#
# What changed, and why "Allow" here does not mean "live":
# This file used to say "Disallow: /". That looked stricter and was actually
# weaker. Google's own docs: "Even if a part of a website is blocked by
# robots.txt, the URLs may be indexed in search (without their content)."
# A page nobody crawls is a page that never receives the noindex telling it to
# go away, so the bare URL stays listable forever.
#
# Crawling is now allowed ON PURPOSE so the three noindex signals already in
# this repo can actually be read and obeyed:
#   index.html   <meta name="robots" content="noindex, nofollow">
#   .htaccess    X-Robots-Tag  (Hostinger, firstwave.mauifoodtruckwebsites.com)
#   _headers     X-Robots-Tag  (Netlify, firstwavecoffee.netlify.app)
#
# So: crawlable, and definitively not indexed. Do NOT put "Disallow: /" back
# thinking it is safer. If First Wave ever adopts this as their official site,
# remove those three noindex signals and add a sitemap line below.
User-agent: *
Allow: /
